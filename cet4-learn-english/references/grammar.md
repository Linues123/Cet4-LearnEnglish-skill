# 语法诊断与纠错

从用户真实表达或刚做过的题中选语言点。四级现行笔试没有独立语法选择题板块；语法微练习是教学补充，不能冒充考试题型或往年原题。

## 批改方法

按“原句 → 最小修改 → 错误位置 → 规则 → 对比例句 → 用户重写”反馈。先处理影响意思的错误，再处理时态、主谓一致、句子结构，最后处理搭配与风格。每轮重点讲1—3类问题，其他问题可以标注待讲，避免一次灌输所有语法。

标明三类判断：明确语法错误／语法成立但表达不自然／可选风格优化。保留用户原意；有歧义时说明两种解释。不要把所有简单句替换成复杂句，或把所有一般过去时改成现在完成时。

## 优先诊断路径

| 现象 | 检查与示范 |
| --- | --- |
| 主谓不一致 | 找真正主语，排除介词短语干扰：The quality of these products **is** good. |
| 谓语缺失或重复 | 判断完整句与从句：Students **who study regularly** often improve. 主句谓语是 improve。 |
| 时间与时态冲突 | 明确结束时间通常配过去时；持续到现在需结合语境判断，不能只凭关键词机械选时态。 |
| 动名词／不定式 | avoid doing；decide to do；look forward to doing 中 to 是介词。 |
| 冠词、单复数 | information、advice、equipment 常作不可数名词，不能写 an advice。 |
| 被动结构 | be + 过去分词，并保留正确时态：The bridge was built last year. |
| 从句连接 | 区分 that 的角色；关系代词取决于先行词及其在从句中的成分。 |
| 逻辑连接重复 | 在标准考试书面英语中避免 Although ... but ... 和 Because ... so ... 双重连接。 |
| 比较与指代 | 比较对象保持平行，明确 it／they／which 所指。 |

## 原创纠错示范

原句：Many students enjoys read English because it help them learning new words.

最小修改：Many students **enjoy reading** English because it **helps** them **learn** new words.

- students 为复数，enjoy 不加 -s；enjoy 后接动名词 reading。
- it 指阅读英语这件事，按单数处理，所以用 helps。
- help someone (to) do 中 learn 或 to learn 都可以；不要误判 to learn 为错。

对比：She enjoys reading. / They enjoy reading.

随后给原创迁移句“我的朋友喜欢看英文新闻，因为这能帮助他了解世界。”等待用户作答。只有用户明确要看完整示范时才展示上述全套答案。

## 长难句讲解

先圈谓语，找主句主谓宾，再划从句／非谓语／插入语，明确连接词和代词关系，最后用自然中文解释。分辨结构如何改变答案判断，而不是仅列语法术语。解析真实句子时引用短语并注明段落位置，不大段重复原文。

## 从基础到长句的教学顺序

| 层次 | 必须会做的事 | 常见检查问题 |
| --- | --- | --- |
| 句子主干 | 判断主语、谓语、宾语／表语 | 谁做什么？句中有几个有时态的谓语？ |
| 名词与修饰 | 判断数、冠词、形容词位置和介词短语范围 | 修饰哪个名词？主语是否被长修饰语隔开？ |
| 动词系统 | 判断时态、被动、非谓语及动词搭配 | 这是主句谓语，还是修饰／目的／补足？ |
| 从句 | 区分定语从句和名词性从句，找连接词角色 | 从句缺什么成分？which／that 指谁？ |
| 逻辑与篇章 | 判断让步、条件、因果、比较与指代 | 原因和结论能否互换？not 修饰哪一部分？ |

每次只教当前错误所需的层次；能正确运用再扩展，不按表格从头灌输一遍。

## 长句拆解示范（原创）

The methods that the teacher recommended to students who struggled with vocabulary have proved useful.

1. 主干：The methods have proved useful. 主语 methods，谓语 have proved，useful 为表语。
2. that the teacher recommended ... 修饰 methods；that 在从句中作 recommended 的宾语。
3. who struggled with vocabulary 修饰 students；who 在该从句中作主语。
4. 中文：老师向那些词汇学习有困难的学生推荐的方法，已经证明很有用。
5. 易错：不要受最近的 vocabulary 影响误选单数谓语；真正主语是 methods。

先让学习者独立找主干，再逐层显示分析。迁移时改换主语和修饰语，检测其能否处理“主语与谓语相隔很远”的新句。

## 纠错范围与可接受答案

英美拼写、合理的词序变化、动名词和不定式都可能有多种正确形式。判错前检查上下文、语义和搭配。对“这个表达不常见”的判断有疑问时核对可靠词典或语法资料；未核验则说明不确定，不绝对化。

例如 “I stopped smoking” 与 “I stopped to smoke” 都可能合语法，但意思不同。纠错要先确认用户想表达“戒烟”还是“停下别的事去抽烟”，不能只按一种搭配删除另一种。
