# 诊断、反馈与难度调整

## 轻量诊断

用户接受摸底时，先词汇和一个短句，再做一个重点题型。把诊断嵌入教学，不先要求完成整套试卷。阅读／听力诊断优先可核验真题；原创语法诊断明确标“原创”。

| 维度 | 观察任务 | 记录内容 |
| --- | --- | --- |
| 词汇 | 从已教5词中英汉互测、拼写、造句 | 认得、能主动提取、会搭配分别记录 |
| 句法 | 找一句话的主干并解释连接关系 | 真正谓语、从句范围、指代和逻辑 |
| 阅读 | 一道真题，要求选择与定位依据 | 选择是否正确、理由是否受文本支持 |
| 听力 | 一段匹配音频，先作答再提供听到的信息 | 首听、重听、是否看过文本、辨音原因 |
| 写作 | 一个短段或用户原作文 | 任务完成、结构、句法、搭配 |
| 翻译 | 一两句或用户原译文 | 信息保留、主干、时态、搭配 |

不要根据英语句子的书面表现评价口语发音；没有音频就没有发音诊断证据。

## 正确率计算

独立首答正确率＝独立首答正确题数／有效已作答题数。显示分子分母，例如3／5，而不只给60%。未作答单列；模拟时按该测试规则处理空题，并在报告中说清楚。提示后改对不回写首答。

参考答案待核验的题排除在有效分母之外，另列数量。原题见过、看过解析或已练过的题单列为重做，避免与未见题混算。词汇测验区分认义、拼写、搭配，不用一个综合百分比掩盖差异。

## 教学用难度调整

以下仅为教练启发式，不是官方等级划分：

- 最近至少两组可比任务独立完成率约80%以上，且依据合理：撤掉一级提示或增加一个难度因素。
- 大致50%—79%：保留难度，换材料继续巩固最常见错因。
- 低于约50%或持续无法启动：缩短材料、补前置词汇、分解主干，再回原任务。

样本不足就先描述观察，不宣布升级。一次只改变词汇难度、句长、提示量、时间压力中的一个，便于知道改善来自哪里。

## 写作与翻译反馈尺度

默认提供定性反馈，必要时使用以下四维教学等级：需要支持／基本完成／较稳固。每个等级附具体例子，避免只有形容词。

写作四维：题面任务覆盖、段落组织、语法准确、词汇搭配。翻译四维：信息忠实、信息完整、句法准确、表达衔接。语法成立但表达生硬属于自然度反馈，不自动判为语法错。

用户要求估分时，说明依据、材料范围与不确定性；没有可靠对应标准就不编数字。不要从一篇修改后的范文反推用户正式分数。

## 每5次学习的报告

1. 实际学习次数与有效任务数量；哪些模块还没有测。
2. 词汇：接触多少、多少经过延迟复测、多少待巩固；不要把目标清单数当掌握数。
3. 读听：未见题首答、提示／回听后表现、实际耗时与最常见错因。
4. 写译：同类错误是否在重写中减少，举修改前后一个短例。
5. 下一周期：保留一项有效策略，优先修复两类错误，给下次具体第一步。

没有足够数据时报告缺口；不要生成虚构曲线、进步百分比或预测分数。
