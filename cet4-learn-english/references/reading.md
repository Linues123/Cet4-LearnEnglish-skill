# 阅读训练：证据先行

先按 `sources.md` 核验原题。训练默认从一篇仔细阅读的小任务起步，随后覆盖长篇匹配和选词填空。完整模考按官方总阅读时限；练习时允许拆题。记录用户是否已见过答案，已见题不计为未见题测试。

## 仔细阅读

1. 用户浏览题干，圈定位信息与限制词：人物、时间、因果、程度、否定。
2. 回原文找相应句群，读前后逻辑，识别同义改写。通常存在顺序线索，但不能把题序当保证。
3. 用户给出选项和依据后，核对主语、范围、程度与因果方向。推断必须受文本支持，不以常识替代证据。
4. 逐项说明错误类型：无中生有、偷换对象、以偏概全、程度夸大、因果倒置、原词干扰、答非所问。不强行为明显正确项寻找错误。

解析至少包含：题目编号、用户选择、参考答案、定位段落、短证据／释义、同义替换、用户错因、一个相关语言点、下一次怎么检查。语言点必须取自实际材料；没有关键语法时说明主要考词汇或逻辑。

## 长篇匹配

先用一句中文概括各段功能；题干圈专有名词、数字与独特观点，搜索对应信息，再核对完整命题。按具体题面规则处理段落复用；不要假定每段只能使用一次。相同词出现不等于匹配成功，特别检查人物、因果和否定是否一致。

## 选词填空

先标候选词性和可能变体，再看空格语法位置、固定搭配及上下文。依次确定词性 → 缩小语义 → 检查逻辑与搭配 → 通读复核。按原题规则使用给定词，不擅自改词形。名词后不一定只能接动词，须看完整结构；一个词也可能有多种词性。

## 原创错误定位示例（不是四级真题）

材料：Although online courses are convenient, some students learn better in a classroom because they need direct feedback.

问题：Which statement is supported?

A. Every student learns better online.
B. Some students benefit from direct feedback in a classroom.
C. Online courses never provide feedback.
D. Classroom learning is convenient for everyone.

教学演示答案：B。A 把 some 扩大为 every；C 的 never 无依据；D 偷换 convenient 所描述的对象。Although 引导让步从句，主句仍是 some students learn better ...；because 说明原因。训练模式先展示材料与选项，等待作答，再展示这些解析。

## 时间策略

在40分钟阅读练习中，可试用仔细阅读20分钟、匹配12分钟、选词填空8分钟，按个人正确率调整；这是训练建议，不是官方分项时限。优先保证能拿分的题，不以固定答案字母分布或“绝对词必错”等猜题口诀代替理解。

## 按问题类型选择证据

| 问题类型 | 先找什么 | 特别防什么 |
| --- | --- | --- |
| 主旨／标题 | 各段功能、重复主题、作者最终结论 | 用某个例子替代全文主题，标题范围过大 |
| 事实细节 | 题干对象与对应句群 | 单词相同但人物、时间、条件不同 |
| 原因／目的 | 明确的因果链、行为目标 | 把结果当原因，把实际效果当原本目的 |
| 推断 | 文本已知信息及其有限延伸 | 用生活经验补出文中没有的事实 |
| 态度 | 评价词、转折、作者与被引用者的立场 | 把他人观点当作者观点 |
| 词义／指代 | 前后句、语法角色、可替换含义 | 用最熟悉词义硬套，代词只找最近名词 |

解析时先说明题目问什么，再找证据。不能为了套分类忽略真实题面。

## 选项核对的四个维度

把选项还原为“谁＋做什么＋条件／范围＋程度”。逐项与证据对照：some 是否被换成 all，may 是否被换成 must，相关是否被说成因果。绝对词是需要检查的信号，不是自动判错规则；原文确实支持绝对结论时仍可能正确。

用户选错时，追问“你是因为哪个词选它的？”如果是原词复现吸引，就让其先判断选项完整命题是否成立；如果是长句读反，就先修复句法再重做，不只讲排除技巧。

## 长篇匹配的可重复操作

第一遍快速建立段落地图，每段只记一个功能词，如问题、调查、反例、解释、建议。第二遍按题干的独特命题去定位，不要求全文逐句翻译。找到候选段后用完整句义验证，并记录为什么另一段只是同主题却不含该命题。

碰到两段相似时比较“谁提出／调查谁／是否有比较／条件是什么”。允许先跳过不确定题，最后回看；题目是否允许重复匹配以具体说明为准。

## 选词填空的检查顺序示范（原创）

句子：The project has made a ___ contribution to local education.

先让用户判断空格词性，再提供候选 significant／significantly／significance。解析时说明：空格修饰名词 contribution，需要形容词 significant；搭配 made a contribution，has made 为谓语。此题是原创微练习；正式真题训练必须保留原文上下文和原选项。

题目完成后重新通读，检查逻辑和词形；词性只缩小候选，不能替代语义判断。

## 阅读复盘留下什么

每篇最多选3—5个最有价值的词或短语和1—2个长句进入复习，不收集所有生词。要求用户用一句中文概括主旨，再复述一条证据；如果答案对但无法概括，下一次练段落理解。

保留题目来源、首答、定位段落、错误类型、重做日期。重复练同一篇可以看方法是否改进，但不能据此推断对新篇章也同样熟练。
