# Cet4-LearnEnglish-skill

一个面向大学英语四级（CET-4）的中文 AI 学习教练 Skill。由 AI 带着你练习：**每次20个优先高频词，先作答再解析，错题讲清原因，再做迁移练习。**

本仓库提供 Skill 文件与使用说明，不会自动安装插件，也不需要专用 API Key。联网查题、音频播放和文件保存能力取决于你使用的 AI 环境。

## 包含什么

| 模块 | 学习方式 |
| --- | --- |
| 单词记忆 | 优先四级常见高频核心词，每批20词、每组5词；释义、搭配、原创例句、主动回忆与间隔复习。内置100词起步池，可继续扩展。 |
| 语法纠错 | 指出错误位置，给最小修改、语法解释和正反例，最后让你重新表达。 |
| 阅读训练 | 优先可核验往年真题，覆盖仔细阅读、长篇匹配和选词填空；讲定位、同义替换、干扰项与长难句。 |
| 作文技巧 | 审题、提纲、分段写作、保留原意的批改与重写，不只给一篇范文。 |
| 汉译英 | 拆信息、定主干、处理时态、检查漏译和搭配，提供可接受的多种表达。 |
| 听力教程 | 真题音频优先，听前预测、首听、回听、精听与跟读；区分首听和回听表现。 |
| 持续学习 | 保存批次、复习日和错题原因，借助进度卡接着上次学。 |

## 不安装插件，怎样使用

1. 在仓库页面选择 **Code → Download ZIP**，解压文件。
2. 在能读取本地文件的 AI 中打开这个文件夹，或者把 `cet4-learn-english/SKILL.md` 和本次模块所需参考文件上传给 AI。
3. 发送下面的启动语。AI 无法读取引用文件时，补充相应文件正文；只贴主文件不会自动让所有模型获得仓库内容。

```text
请读取 cet4-learn-english/SKILL.md，并按其中要求担任我的四级英语教练。
我每天有40分钟，基础一般。先从四级常见高频核心词开始，本次20个，
分成每组5个带我记忆并测试。之后安排阅读真题训练。
先让我回答，再讲答案、错误点和用到的语法；不要提前泄露答案。
不安装任何插件。
```

如果你的 AI 已经通过其支持的方式加载了该 Skill，也可以使用：

```text
请使用 $cet4-learn-english 带我学习。
```

`$cet4-learn-english` 不是通用安装命令；在没有技能发现机制的普通聊天中，使用上面的“读取文件”方式即可。

## 常用指令

```text
今天只背单词：20个，优先高频。每组5个，考我后再继续。
这是上次的进度卡，请先复习到期词，再接着未完成的那一批。
找一道可核验的往年四级阅读题。先让我选，并说明我错在什么地方。
这道题我选C，请结合原文定位，解释其余选项为什么不合适，并拆解相关长句。
请修改我的英文句子，区分语法错误和可选的表达优化，再出一道迁移练习。
用往年四级作文题带我审题和列提纲，先不要给范文。
批改这段汉译英：先查漏译和意思，再讲语法与搭配。
带我练一段四级真题听力，先给音频来源和选项，作答前不要展示原文。
今天结束，请输出我下次可以直接粘贴使用的完整进度卡。
```

## 每次20词如何执行

一次记忆课建立20个不同目标词，按4组互动。上一批没完成时，“继续”会接着该批，不重新塞入20词。旧词复习另计，易混词或派生词不偷偷增加新词数。用户明确要求改数量时可以调整。

起步池为5批、共100个常见核心词，按教学场景编排，**不是官方词频排名，也不是完整四级词表**。有可核验词频表或真题语料时优先用它调整学习顺序；不会编造某个词的真题次数。

## 真题与音频怎么获得

仓库提供[已检查的真题入口与核验流程](cet4-learn-english/references/sources.md)，不打包第三方整套试卷、音频和商业解析。AI 先核对考试年月、套别、题号、题面与答案来源，之后再使用。阅读、写作、翻译与听力均优先寻找往年题；原创例子和迁移练习会明确标注。

例如，可从[2024年12月第1套自测页面](https://eol.nju.edu.cn/cet4/papers/202412-1.html)的仔细阅读46—50题选择训练，使用时再核对原题与参考答案。也可从 [WeHUSTER 真题目录](https://www.wehuster.com/cet4)选择题目。第三方整理内容不是命题机构的官方答案。

AI 无法访问网页时，你可以提供题目文字、截图、PDF或相关片段；没有可核验真题时会说明，而不会编造“往年原题”。只接受真题时可以明确说“找不到先不出题”。

听力需要可用音频。AI 无法直接播放或听取音频时，会说明并引导你在来源页播放；只有文字时可以练技巧，但不算已完成听力测试。合成语音会单独标注。

## 进度与隐私

使用[空白进度卡](cet4-learn-english/assets/progress-template.md)保存学习记录。默认复习间隔为当次结束及1／3／7／14／30天后，可按记忆表现调整。复习安排不等于系统自动提醒。

新会话未必记得旧会话，请粘贴上次进度卡或让 AI 读取已保存记录。本仓库的 `.gitignore` 排除了 `progress/` 与 `materials/`，避免误提交实际学习记录与题目材料；上传前仍应检查文件清单。
