# Cet4-LearnEnglish-skill

一个面向大学英语四级（CET-4）的中文 AI 学习教练 Skill。由 AI 带着你练习：**每次20个优先高频词，先作答再解析，错题讲清原因，再做迁移练习。**

本仓库提供 Skill 文件与使用说明，不会自动安装插件，也不需要专用 API Key。联网查题、音频播放和文件保存能力取决于你使用的 AI 环境。

## 包含什么

增强版补齐了阶段课程、诊断评价、难度调整和8个互动教学场景。每个专项除方法概述，还包含可执行步骤、典型错因、原创示范及复测办法；完整资料按需读取，实际学习仍逐轮推进。

| 模块 | 学习方式 |
| --- | --- |
| 单词记忆 | 优先四级常见高频核心词，每批20词、每组5词；释义、搭配、原创例句、主动回忆与间隔复习。内置100词起步池，可继续扩展。 |
| 语法纠错 | 指出错误位置，给最小修改、语法解释和正反例，最后让你重新表达。 |
| 阅读训练 | 优先可核验往年真题，覆盖仔细阅读、长篇匹配和选词填空；讲定位、同义替换、干扰项与长难句。 |
| 作文技巧 | 审题、提纲、分段写作、保留原意的批改与重写，不只给一篇范文。 |
| 汉译英 | 拆信息、定主干、处理时态、检查漏译和搭配，提供可接受的多种表达。 |
| 听力教程 | 真题音频优先，听前预测、首听、回听、精听与跟读；区分首听和回听表现。 |
| 持续学习 | 保存批次、复习日和错题原因，借助进度卡接着上次学。 |

## 不安装插件，怎样使用

1. 在仓库页面选择 **Code → Download ZIP**，解压文件。
2. 在能读取本地文件的 AI 中打开这个文件夹，或者把 `cet4-learn-english/SKILL.md` 和本次模块所需参考文件上传给 AI。
3. 发送下面的启动语。AI 无法读取引用文件时，补充相应文件正文；只贴主文件不会自动让所有模型获得仓库内容。

```text
请读取 cet4-learn-english/SKILL.md，以及本次学习所需的参考文件，
担任我的大学英语四级学习教练，用中文解释，用英文带我练习。
如果你无法读取这些文件，请明确告诉我缺少哪个文件，不要假装已经加载。

【我的情况】
我暂按基础一般、每天40分钟开始，考试日期和目标成绩待补充。
你可以集中简短询问一次必要信息，但先带我开始学习，不要用长问卷阻塞开课。
请根据我的实际回答判断各项能力，不要凭一句自评就给我定级。

【本次安排】
1. 如果有上次进度，先恢复未完成批次并复习到期词；没有就开始新批次。
2. 每个新批次20个不同目标词，优先四级高频核心词，每组5个互动。
   每词讲词性、常用义、发音提示、搭配、记忆线索、原创例句及译文。
   没有可核验词频数据时说明选词依据，不编造排名或出现次数。
3. 每组讲完先让我主动回忆，再检测拼写、搭配或造句；批末打乱顺序复测。
   旧词复习另计。时间不够就保留本批进度，下次续学，不把未测词记为掌握。
4. 时间允许时，安排一个与我的弱项有关的专项，首次优先阅读真题。

【真题与讲解】
阅读和其他题型优先用可核验的往年四级题，注明年月、套别、题号和来源。
无法核验时先说明缺口，请我提供材料；原创题或改编题要明确标注，不能冒充真题。
练习时先只给题面和必要说明，等待我的答案与理由，再给解析。
阅读解析请指出定位证据、同义替换、干扰项错因和真正相关的语法。
语法纠错请给最小修改、原因、正反对比例子，再让我用新句子检验。
写作和翻译先检查任务及原意，再修改语言，保留我表达中正确的部分。
听力先确认音频可用，首听前不展示原文、译文和答案。

【互动方式】
一次给一个清晰任务，完成当前步骤后等待我回答，不要一次输出整节课的答案。
我说“不会”时，先给一级提示；仍有困难再逐步降低难度。
区分独立答对、提示后答对、看过解析后重做，不用泛泛鼓励代替具体反馈。
课末给我实际完成情况、主要错因、复习安排和可复制的完整进度卡。
不安装插件。现在请说明本次目标，直接开始第一组5词的教学，检测题另轮发送。
```

## 常用指令

以下每个代码框都是一条可以单独复制的消息，选择当前需要的一条即可。在已经加载 Skill 的会话中直接发送；新会话先加载文件或发送上面的首次启动语。带“粘贴在下方”的模板，请在同一条消息末尾补充真实材料；没有材料时说明需要 AI 找题。

### 1. 专门背20个单词

```text
请按本 Skill 带我上一节四级单词记忆课。
有未完成的20词批次就继续该批；没有才新建20个不同目标词，优先高频核心词。
先检查到期复习，旧词复习另计，并说明新词的选择依据。

每次教5词，每词包含词性、核心义、可靠发音提示、常见搭配、记忆线索和原创例句。
不要一次罗列所有义项；遇到易混词用具体语境对比，派生词不额外计入本批数量。
讲完一组后另轮发无答案的检测，让我做英汉回忆、拼写和语境运用。
先等我回答，再逐项批改；错词课末再测，之后安排间隔复习。
请分别记录“认识意思、能默写、能使用”，不要用选择题猜中代替掌握。
现在只开始当前组教学，等我准备好再检测。
```

### 2. 往年真题阅读带练

```text
请带我练四级阅读，默认从一篇仔细阅读开始；我指定其他阅读题型时按我的要求。
优先找我未做过、适合当前水平的往年真题，核验年月、套别、题号、原文和选项。
先给来源与练习范围。需要完整原文时让我打开来源或使用我提供的材料。
找不到可核验题目就说明缺口，先不要自行编一道并称为真题。

先让我读题、选择并说明依据；不要提前给答案、全文译文或关键定位提示。
我答完后，请按以下顺序讲解：
①题目究竟问什么；②原文定位与短证据；③正确项如何同义改写；
④其他各项错在哪里；⑤我的思路最早在哪一步偏离；
⑥影响理解的词汇和语法，用正反例说明；⑦下一题可复用的检查步骤。
如果我选对但理由不成立，请追问证据，不能直接判为已经会做。
最后找一道同考点往年题巩固；无法核验时说明，原创迁移题需先征得我同意。
一次只推进一个任务，现在先准备题目并等待我作答。
```

```text
对相关长句先找主干，再标从句和修饰范围，说明它如何影响选项判断。
给一个正反对比例子，让我看清正确理解和错误理解的差别。
最后让我重新说出本题依据，再安排一题同考点迁移；先不要替我回答。
```


### 7. 汉译英逐句带练

```text
请带我练四级汉译英，优先使用可核验往年真题；有我提供的中文就优先使用。
先给来源和中文材料，每轮1—2句，不提前展示参考译文。

批改时先查漏译、增译和意思改变，再看主干、时态、语态、搭配与衔接。
```

### 8. 真题听力与精听教程

```text
请带我练四级真题听力，从适合我水平的一段开始，注明年月、套别、题号和音频来源。

先带我预读选项、比较差异，不提前展示原文、译文和答案。
```

## 每次20词如何执行

一次记忆课建立20个不同目标词，按4组互动。上一批没完成时，“继续”会接着该批，不重新塞入20词。旧词复习另计，易混词或派生词不偷偷增加新词数。用户明确要求改数量时可以调整。

起步池为5批、共100个常见核心词，按教学场景编排，**不是官方词频排名，也不是完整四级词表**。有可核验词频表或真题语料时优先用它调整学习顺序；不会编造某个词的真题次数。

## 真题与音频怎么获得

仓库提供[已检查的真题入口与核验流程](cet4-learn-english/references/sources.md)，不打包第三方整套试卷、音频和商业解析。AI 先核对考试年月、套别、题号、题面与答案来源，之后再使用。阅读、写作、翻译与听力均优先寻找往年题；原创例子和迁移练习会明确标注。

例如，可从[2024年12月第1套自测页面](https://eol.nju.edu.cn/cet4/papers/202412-1.html)的仔细阅读46—50题选择训练，使用时再核对原题与参考答案。也可从 [WeHUSTER 真题目录](https://www.wehuster.com/cet4)选择题目。第三方整理内容不是命题机构的官方答案。

AI 无法访问网页时，你可以提供题目文字、截图、PDF或相关片段；没有可核验真题时会说明，而不会编造“往年原题”。只接受真题时可以明确说“找不到先不出题”。

听力需要可用音频。AI 无法直接播放或听取音频时，会说明并引导你在来源页播放；只有文字时可以练技巧，但不算已完成听力测试。合成语音会单独标注。

## 进度与隐私

使用[空白进度卡](cet4-learn-english/assets/progress-template.md)保存学习记录。默认复习间隔为当次结束及1／3／7／14／30天后，可按记忆表现调整。复习安排不等于系统自动提醒。

新会话未必记得旧会话，请粘贴上次进度卡或让 AI 读取已保存记录。本仓库的 `.gitignore` 排除了 `progress/` 与 `materials/`，避免误提交实际学习记录与题目材料；上传前仍应检查文件清单。

## 一个学习周期会怎样进行

1. **摸底与计划**：结合实际回答确认弱项，按每天15／40／60分钟安排任务；每批新词保持20个。
2. **分组学习**：每组5词，讲解后遮住答案，先测认义，再测拼写和搭配。基础薄弱时同一批可以分几次完成。
3. **专项带练**：优先往年题，先做题和说明理由，再看证据、错因及相关语法；最后用另一题检验方法。
4. **写译重写**：先核对题面和原意，再改语言；AI保留你的表达，并让你独立重写关键部分。
5. **听力分层**：根据困难选择辨音、意群、语篇或考试任务；首听、回听和看文本后表现分开记录。
6. **续学与调整**：课末生成完整进度卡，每5次实际学习复盘一次，依据新材料表现调整提示量和难度。

你可以说“用基础模式，解释慢一点”“今天只练一个阅读题型”“进入限时训练”“只接受可核验真题”或“先别讲答案，给一级提示”。

## 资料完整与课堂节奏

本 Skill 的参考资料用于帮助AI提供完整教学；不会要求每次把所有内容输出给你。需要系统教程时可以说“先完整讲解这个模块，再开始互动训练”；需要陪练时可以说“一次只给一个任务，等我回答”。

当前词汇资源是100词起步池，后续按可靠高频词表和真题生词扩展，不声称已内置全部四级词库。真题仍按来源核验后使用；新增的教学例子均明确标注原创。

考试规则以[中国教育考试网](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)最新公告为准。训练正确率或作文教学评价不等于正式710分制成绩。本项目不是官方考试产品。
